This tool is intended to make it easier to access and download digitised archival materials from the Dutch National Archives (Nationaal Archief). The archival materials remain subject to the rights and usage conditions applicable to them. Please consult the Nationaal Archief for further information about the use and reproduction of these materials.

This is a small research-oriented project, shared for convenience and scholarly use. The source code is available on https://github.com/asyrafi-m/nationaalarchief-downloader. Muhammad Masruhan provided valuable insights into the user experience and helped test this tool.
